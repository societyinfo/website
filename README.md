# NPRE Luxembourg — Website v1.0

Static GitHub Pages-ready website for the community initiative:

**Nepalese Professionals, Researchers & Entrepreneurs in Luxembourg**

Tagline: **Connect. Learn. Share. Grow.**

## Files
- `index.html` — main website
- `css/style.css` — responsive styling
- `js/script.js` — mobile navigation and expression-of-interest form

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `npre-luxembourg`.
2. Upload these files, keeping the folder structure.
3. In GitHub: **Settings → Pages → Deploy from a branch**.
4. Select the main branch and `/ (root)`.
5. GitHub will provide the Pages address.

## Before public launch
In `js/script.js`, replace:
`REPLACE_WITH_SOCIETY_EMAIL`
with the official email address or, preferably later, connect the form to a suitable privacy-conscious form service.

## Future migration
The site deliberately uses ordinary HTML/CSS/JavaScript. It can later be moved to professional hosting and a `.lu` domain without rebuilding the front end.

## Privacy
The current form uses a mailto link and does not create a server-side database. Do not publish a personal/community roster publicly without appropriate consent and privacy information.
